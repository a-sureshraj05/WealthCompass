# Brokerage marks

These are existing brokerage favicons, bundled so Accounts & Imports works
without requests to an external logo service. They identify the brokerage;
they do not indicate affiliation or connection health.

- Fidelity: https://www.fidelity.com/favicon.ico (ICO converted to PNG)
- Robinhood: https://robinhood.com/favicon.ico (ICO converted to PNG)
- Vanguard: https://investor.vanguard.com/favicon.ico (ICO converted to PNG)
- Charles Schwab: Google favicon cache for schwab.com, 128px PNG.
  The official root and theme favicon endpoints returned HTML error pages.
- E*TRADE: Google favicon cache for etrade.com, 128px PNG.
  The official endpoint did not complete successfully.

Retrieved October 31, 2026. Original marks and colors are preserved.
