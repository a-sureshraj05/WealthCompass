# snaptrade-python-sdk is DELIBERATELY ABSENT.
#
# 11.0.169 (the version installed locally) hard-pins typing_extensions==4.13.2,
# which pydantic 2.12.5 cannot satisfy — it needs >=4.14.1. That is an
# unsatisfiable resolve, not a preference. Notably the local environment has
# typing_extensions 4.15.0 installed, so the local combination already violates
# that pin and merely happens to work; pip would not reproduce it.
#
# 13.0.1 relaxes the pin to <5,>=4.13.2 and would resolve cleanly, but bumping
# the brokerage SDK two major versions to ship a demo that never calls it puts
# the one code path that syncs real accounts at risk for no benefit.
#
# So the image ships without it. backend/app/api/snaptrade.py tolerates the
# missing import, and every brokerage route on the demo returns 503 before it
# could matter. Local development is unaffected — keep 11.0.169 installed there.
# Revisit only if the hosted instance ever needs real brokerage sync (Stage 3),
# which requires per-user credentials anyway.
